# ☁️ AWS Pharmacy Cloud Project

## Sobre o Projeto
Esse projeto apresenta a concepção de uma plataforma virtual para uma farmácia fictícia utilizando serviços da AWS (Amazon Web Services).

O objetivo é aplicar conceitos de computação em nuvem em um cenário prático, focando em:
- escalabilidade;
- disponibilidade;
- segurança;
- redução de custos;
- infraestrutura cloud.

---

## ⚙️ Serviços AWS Utilizados
O projeto considera a utilização de serviços como:
- Amazon EC2
- Amazon S3
- Amazon RDS
- AWS IAM
- Amazon CloudFront
- AWS Lambda

---

## 🎯 Objetivos
- Criar uma arquitetura cloud para uma farmácia virtual
- Melhorar disponibilidade e desempenho
- Reduzir custos operacionais
- Garantir segurança e escalabilidade
